## Mengapa Memilih Kinetics?

<CardGrid stagger>
	<Card title="Fokus di Server" icon="rocket">
		Semua kerja keras dilakukan oleh Laravel. Pengurutan, pencarian, dan paginasi diolah murni lewat Eloquent, menjaga browser pengguna tetap ringan.
	</Card>
	<Card title="React Tanpa Boilerplate" icon="document">
		Cukup tempatkan satu komponen `<Table table="data" />` di halaman Inertia Anda, dan Kinetics akan otomatis menyusun UI yang utuh dari ujung ke ujung.
	</Card>
	<Card title="Pipeline Bebas Modifikasi" icon="setting">
		Berjalan di atas arsitektur Pipeline bawaan Laravel. Anda bisa mengubah, menyuntikkan, atau mencabut tahapan query sesuai kebutuhan bisnis Anda.
	</Card>
	<Card title="Desain Kelas Menengah Atas" icon="open-book">
		Kinetics menolak tampilan usang. Komponen frontendnya dirancang sangat modern, aksesibel, dan sudah terintegrasi secara *native* dengan `shadcn/ui`.
	</Card>
</CardGrid>
