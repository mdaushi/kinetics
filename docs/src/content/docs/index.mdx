## Why Kinetics?

<CardGrid stagger>
	<Card title="Server-Side First" icon="rocket">
		The heavy lifting is done by Laravel. Sort, search, filter, and paginate are fully handled natively by Eloquent, so your browser stays lightning fast.
	</Card>
	<Card title="Zero-Boilerplate React" icon="document">
		Stop copy-pasting massive table components. Just drop `<Table table="data" />` into your Inertia page and watch the magic happen.
	</Card>
	<Card title="Fully Composable Pipeline" icon="setting">
		Kinetics uses Laravel's native Pipeline architecture. You can easily modify, inject, or remove query stages according to your specific business logic.
	</Card>
	<Card title="Beautiful by Default" icon="open-book">
		We don't do ugly. The frontend component is a modern, accessible, and responsive interface integrated deeply with `shadcn/ui` and Tailwind CSS.
	</Card>
